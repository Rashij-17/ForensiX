# Code of Conduct

We are committed to a respectful, harassment-free experience for everyone.

**Expected:** be considerate, give and accept constructive feedback gracefully, focus on what is best for the
project and its users, and respect differing viewpoints.

**Not acceptable:** harassment, insults, personal attacks, publishing others' private information, and using ForensiX
to create, improve or distribute deceptive synthetic media.

Maintainers may remove contributions that violate this code and may ban repeat offenders. Report concerns to the
maintainers through a private GitHub message. This code is adapted from the Contributor Covenant, version 2.1.
