# Test samples

Tiny **synthetic** files generated by `forensix.data.synthetic` for trying the app and the API.
They are *not* real deepfakes and *not* from the DeepSafe dataset; the `*_manipulated_demo` files carry
artificial generator-like artefacts that the demo-trained models are built to find.

| File | Use |
|------|-----|
| `image_authentic_demo.jpg`, `image_manipulated_demo.png` | Analyze / Evidence |
| `image_manipulated_demo_recompressed.jpg` | Compare against `image_manipulated_demo.png`; Forensic Lab |
| `audio_*_demo.wav`, `video_*_demo.mp4` | Analyze / Evidence / Lab |
